BILBY — сайт из двух страниц

Файлы:
- index.html — главная страница: официальный промопостер, описание путешествия и встроенный видеоплеер.
- history.html — история создания мультфильма и фотография только одного режиссёра: Pierre Perifel.
- styles.css — общий дизайн, адаптивная верстка и фоновые изображения.
- script.js — плавное переключение фоновых сцен при прокрутке.

Как открыть:
1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Для загрузки фоновых фотографий, постера, портрета и шрифтов требуется интернет.
