# Путь к сердцу — четырёхстраничный сайт

## Страницы
- `index.html` — краткое описание короткометражки, промопостер и видеозапись на Rutube.
- `history.html` — подробная история разработки, команда, визуальный стиль и премьера.
- `rest.html` — практические рекомендации по сну, перерывам и восстановлению.
- `research.html` — официальные рекомендации и научные публикации о сне, движении и коротких перерывах.

## Запуск
Распакуйте архив и откройте `index.html` в браузере. Для перехода между страницами используйте верхнее меню. В меню «Выбрать фон» можно установить собственное изображение; оно сохраняется в localStorage браузера и применяется на всех страницах сайта.

## Постер
На главной странице используется промопостер Inner Workings с брендингом Disney, размещённый в карточке фильма на Prime Video:
https://www.primevideo.com/detail/0LLQ1CEKU3Z32CRBP30DSU7LVE/
Изображение загружается с CDN Amazon; для отображения постера требуется подключение к интернету. Дополнительные официальные материалы о фильме доступны на Disney+ и D23.

## Видео
Встроенный плеер использует видеозапись на Rutube:
https://rutube.ru/video/fa60d6e495fed10345ba9c9247404737/
Это пользовательская загрузка, а не официальный канал Disney. Доступность ролика определяется Rutube и правообладателем. Если ролик недоступен, на странице есть ссылка на поиск Inner Workings в Rutube. Полная карточка фильма доступна на Disney+:
https://www.disneyplus.com/browse/entity-b275ce77-427f-4b49-9f25-febebbd45f26
